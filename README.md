## 🚀 Featured Project: Garimotors

**Live Demo:** [garimotors.vercel.app](https://garimotors.vercel.app) · **Source Code:** [github.com/haron-murumba/garimotors](https://github.com/haron-murumba/garimotors)

A full-stack marketplace where sellers list vehicles and buyers contact them directly.

- **Frontend:** React, Vite, Tailwind, Apollo Client
- **Backend:** Django, Graphene (GraphQL), PostgreSQL
- **Deployed on:** Render, Vercel, Neon, Cloudinary
- **Key Features:** JWT Auth (Buyer/Seller/Staff roles), Image Upload, Seller Dashboard, Staff Admin Panel.
